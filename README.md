# Telegram-бот задач

Минимальный бот на Python, aiogram 3 и встроенном SQLite3. Код функций снабжён пояснениями на русском. Работа с задачами доступна в личном чате с ботом.

## Запуск в Windows (PowerShell)

Нужен Python 3.10–3.14. В папке проекта выполните:

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

Откройте [@BotFather](https://t.me/BotFather) в Telegram, отправьте `/newbot`, задайте имя и уникальное имя пользователя, оканчивающееся на `bot`. Полученный токен вставьте в файл `.env`:

```dotenv
BOT_TOKEN=сюда_токен_от_BotFather
DB_PATH=data/tasks.db
```

Пустой `.env` уже создан. Если файла нет, скопируйте `.env.example` в `.env`. `.env` исключён из Git. Переменные окружения имеют приоритет над `.env`.

Запустите бота:

```powershell
.\.venv\Scripts\python.exe bot.py
```

В Telegram откройте своего бота и отправьте `/start`. Бот работает, пока запущен процесс; остановка — `Ctrl+C`. Запускайте только один процесс для одного токена.

## Команды

| Команда | Результат |
| --- | --- |
| `/start` | Приветствие и список команд |
| `/add Купить молоко` | Сохранение задачи |
| `/add` | Пример правильного использования |
| `/list` | Свои задачи в порядке добавления |
| `/list_csv` | Файл `tasks.csv` со своими задачами |

Каждый пользователь видит только задачи со своим числовым Telegram ID. При пустом списке `/list_csv` отправляет файл с заголовками. Длинный `/list` отправляется несколькими сообщениями.

## Хранение

База создаётся автоматически по пути `data/tasks.db`. Относительный `DB_PATH` считается от папки проекта, даже если команда запускается из другой папки.

Таблица `tasks` содержит `id` (автоматический ID), `text`, `user` (Telegram ID владельца) и `created_at` (время UTC). Изменения сохраняются после каждого `/add`; перезапуск не удаляет базу. Для резервной копии остановите бота и скопируйте файл базы.

## CSV и эксперименты

CSV использует разделитель `;`, кодировку UTF-8 с BOM и корректное экранирование кавычек, разделителей и переносов строк. Если Excel не разделил колонки автоматически, импортируйте через **Данные → Из текста/CSV**, выбрав UTF-8 и разделитель `;`. В LibreOffice Calc при открытии укажите те же параметры.

В выгрузке есть колонки `id`, `text`, `user`, `created_at` и две пустые колонки **Статус** и **Категория**. Их можно заполнить в Excel или LibreOffice и сохранить CSV. Правки файла не изменяют задачи в SQLite: обратный импорт не предусмотрен. Текст, начинающийся со знака формулы, экспортируется с апострофом, чтобы таблица воспринимала его как текст.

Для проверки задания:

1. Добавьте несколько разных задач: `/add Купить молоко`, `/add Позвонить другу`, `/add Проверить "кавычки"; разделитель`.
2. Выполните `/list` и проверьте порядок.
3. Остановите бота (`Ctrl+C`), запустите снова и проверьте `/list`: задачи должны сохраниться.
4. Выполните `/list_csv`, скачайте и откройте файл в Excel или LibreOffice.
5. Заполните «Статус» и «Категория», сохраните файл и откройте повторно.

## Автоматическая проверка без Telegram

```powershell
.\.venv\Scripts\python.exe -m unittest discover -s tests -v
```

Тесты используют временную базу и подменяют отправку сообщений Telegram. Проверяются сохранение после повторного открытия, порядок, разделение пользователей, CSV с кириллицей и специальными символами, обработка команд и длинных списков. Настоящий токен не нужен.

Документация: [aiogram — команды](https://docs.aiogram.dev/en/latest/dispatcher/filters/command.html), [получение обновлений](https://docs.aiogram.dev/en/latest/dispatcher/long_polling.html), [отправка файлов](https://docs.aiogram.dev/en/latest/api/upload_file.html).
